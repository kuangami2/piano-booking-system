# 代码仓实现清单

琴房预约系统代码仓结构与实现清单，2026-09-11。配套答辩材料 `docs/项目概况与答辩准备.docx` 第十章。

## 一、分层与目录
| 层 | 包路径 | 文件数 | 职责 |
| --- | --- | --- | --- |
| 启动与配置 | 根包、config、config/interceptor | 8 | 启动类、跨域、MyBatis-Plus、拦截器注册、鉴权与角色注解、种子数据初始化 |
| 接口层 | controller、controller/admin | 18 | 用户端 9 个与管理端 9 个控制器，参数接收与返回包装 |
| 业务层 | service、service/impl、service/admin | 20 | 预约核心、用户、关注、规则缓存、缓存、限流、计分、风控与管理端八类业务 |
| 数据层 | mapper、entity | 22 | 11 张表的实体与 Mapper，含房间行锁注解 SQL |
| 公共与工具 | common、dto、exception、task、utils | 13 | 统一返回、常量、规则键、开关、异常、定时任务与 Token 工具 |

## 二、用户端接口模块
| 模块 | 主要文件 | 关键实现点 |
| --- | --- | --- |
| 鉴权与用户 | AuthController、ISysUserService、SysUserServiceImpl、JwtInterceptor、TokenUtils | BCrypt 密码、token 以密码 hash 加签、改密即失效、重复注册校验 |
| 琴房浏览 | RoomController、RoomMapper | 普通用户仅见对外琴房、详情含乐器、列表缓存 60 秒 |
| 空闲查询 | RoomController.free、FreeSlot | 按最小单位分块标记占用再合并区间、当天只返回当前时刻之后时段、缓存 30 秒 |
| 预约核心 | BookingController、IBookingService、BookingServiceImpl | 十步校验、规则快照、行锁串行化、区间重叠检测、唯一键兜底转 409、写后失效与计分 |
| 我的预约与退约 | BookingController、BookingServiceImpl.cancelBooking | 状态机流转、周退约限制、退约即释放并触发提醒、计入临近取消与负分 |
| 关注与提醒 | WatchController、IWatchService、MessageController | 区间重叠匹配关注者、站内消息写入、关注状态置已提醒 |
| 消息与反馈 | MessageController、FeedbackController | 消息列表与已读、反馈提交与查询 |
| 内容展示 | ContentController | 轮播、公告、规则公开视图 |
| 排行榜 | RankingController、ActivityService | 六类事件按权重计分、周榜月榜自然滚动、脱敏昵称、最终一致 |
| 风控状态 | RiskController、RiskService | 返回本人是否受限、解除时间与临近取消计数 |

## 三、管理端接口模块
| 模块 | 主要文件 | 关键实现点 |
| --- | --- | --- |
| 用户管理 | AdminUserController、AdminUserService | 列表查询、会员设置、密码重置 |
| 琴房管理 | AdminRoomController、AdminRoomService | 增删改查与乐器整体覆盖、改动后清理列表与空闲缓存 |
| 预约管理 | AdminBookingController、AdminBookingService | 按日期房间用户状态查询、取消处理 |
| 规则参数 | AdminRuleController、AdminRuleService | 批量更新后刷新规则缓存，用户端即时生效 |
| 信用管理 | AdminCreditController、AdminCreditService | 人工减分与恢复、写流水、低于阈值暂停预约 |
| 内容管理 | AdminContentController、AdminContentService | 公告与轮播维护、图片保存到运行目录 |
| 反馈处理 | AdminFeedbackController、AdminFeedbackService | 列表与状态流转 |
| 统计 | AdminStatsController、AdminStatsService | 概览指标与琴房使用率计算 |
| 文件访问 | UploadController | 按文件名读取上传图片，公开访问 |

## 四、公共与基础设施
| 组件 | 文件 | 说明 |
| --- | --- | --- |
| 统一返回 | Result、Constants | code、msg、data 与业务码定义 |
| 全局异常 | GlobalExceptionHandler、ServiceException、RiskBlockedException | 业务与风控异常统一包装，风控异常带 data |
| 规则键与开关 | RuleKeys、EnhanceProperties | 预约、信用、活跃度权重与风控参数键；缓存、限流、计分与风控开关 |
| 缓存 | CacheService | Redis 优先、进程内回退、前缀失效、异常后暂停重试 30 秒 |
| 限流 | RateLimitService | 固定窗口计数、场景与用户维度、阈值可配 |
| 定时任务 | BookingAutoFinishTask、CreditRestoreTask | 预约过期与当天结束释放、信用每日恢复 |
| 种子数据 | DataInitializer | 空库写入管理员与演示用户、五间琴房与乐器、十五条规则、公告与轮播 |
| 数据库脚本 | docs/schema.sql 与 backend/sql 三个迁移脚本 | 建库建表、索引补强、阶段 B 规则补种、唯一约束修正 |

## 七、阅读建议
1. 先看 config 与 common 了解启动与统一约定，再看 controller 理解接口边界。
2. 重点读四个类：BookingServiceImpl 预约核心、RiskService 风控、ActivityService 计分、CacheService 缓存。
3. 数据库细节看 docs/schema.sql 与 docs/架构说明.md 第三章。
4. 接口约定看 docs/接口清单.md v0.5，权限拦截看 JwtInterceptor。
