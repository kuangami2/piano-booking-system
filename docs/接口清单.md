# 房间预约系统：接口清单

状态：v0.1 初稿，2026-09-07，供三人评审后冻结。

## 一、约定
1. 基础路径 /api，请求与响应 JSON，UTF-8。
2. 统一响应 Result：{code,msg,data}。code 200 成功，400 参数错误，401 未登录或 token 失效，403 无权限，404 资源不存在，409 业务冲突如时段被占。
3. 鉴权无状态 JWT：登录返回 token，请求头 Authorization: Bearer token，公开接口除外。
4. 分页参数 page 从 1 起，size 默认 10，data 返回 {list,total}。
5. 时间表达：预约与关注的时间用当日 HH:mm 字符串，如 10:00；表存当日分钟偏移；粒度与时长由后端按规则校验。
6. 日期用 YYYY-MM-DD。

## 二、鉴权 auth，公开
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/auth/register | 注册 {username,password,name,studentNo,email} |
| POST | /api/auth/login | 登录 {username,password}，data 返回 {token,user} |
| GET | /api/auth/profile | 当前用户信息，需登录 |
| PUT | /api/auth/password | 修改密码 {oldPassword,newPassword} |
| POST | /api/auth/forgot | 邮箱找回 {email}，发送重置链接 |
| POST | /api/auth/reset | 凭链接 token 重置 {token,newPassword} |

## 三、琴房浏览 room，需登录，普通用户仅见对外琴房
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/rooms | 琴房列表，参数 type=inner 或 outer、q 名称关键字、page、size；会员与管理可见对内 |
| GET | /api/rooms/{id} | 详情，含 instruments 乐器明细与注意事项，对内琴房校验会员 |
| GET | /api/rooms/{id}/free | 空闲时段，参数 date；data 返回当日可约连续区间 [{start,end}]，已按最小单位、时间窗、提前天数过滤并扣除已约时段 |

## 四、预约 booking，用户
| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /api/bookings | 创建预约 {roomId,date,start,end}；校验对内权限、信用暂停、周次数、时长上下限、提前天数、时间窗与冲突；冲突返回 409 |
| GET | /api/bookings/mine | 我的预约，参数 status=booked、cancelled、finished，page |
| DELETE | /api/bookings/{id} | 退约取消，仅本人且 booked 可退；成功立即释放时段并触发关注提醒，计入周退约次数 |
