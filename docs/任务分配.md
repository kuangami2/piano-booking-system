## 三、纪律
1. 接口冻结：契约 v0.8 为当前版本，新增或变更先改 接口清单.md 并标注版本，未冻结不得实现。
2. 分支与同步：master 为发布主线，develop 为集成基线；组员在个人分支开发并推远端，组长拉取集成后合入 develop 再同步。
3. 降级：增强依赖不可用时回退原路径，预约创建、冲突检测与退约状态更新始终在数据库事务内同步完成。
4. 质量：每阶段扩展验收脚本断言，新增业务分支同步补单测。
