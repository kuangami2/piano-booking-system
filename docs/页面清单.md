# 房间预约系统：页面清单

状态：v0.1 初稿，2026-09-07。

## 一、用户端页面，路由前缀 /
用户端工程为 `frontend/user-web`，Vue3 加 Vite 加 Element Plus；当前路由使用占位组件，各页面调用的接口见 接口清单.md。

1. 登录注册 /login，含注册、忘记密码、重置密码子视图。
2. 首页 /home，轮播、公告、琴房快捷搜索与入口。
3. 琴房列表 /rooms，对内对外筛选与关键字搜索，分页。
4. 琴房详情 /rooms/:id，琴房说明、乐器明细、注意事项、空闲查询、预约表单与空出提醒关注。
5. 我的预约 /bookings，按状态筛选，退约取消。
6. 我的关注 /watches，关注时段列表与取消。
7. 消息中心 /messages，站内提醒列表与已读。
8. 个人中心 /profile，资料展示、会员状态、修改密码。
9. 反馈 /feedback，提交反馈与我的反馈记录。

### v1.1 候选页面

10. 活跃度排行榜 /ranking/activity，展示周榜/月榜、本人排名与分数；数据为最终一致，接口或 Redis 不可用时提供重试提示。
11. 预约风控提示（复用 /rooms/:id 预约表单），命中临近取消黑名单时展示原因、解除时间和规则说明，不展示其他用户的风控信息。

## 二、管理端页面，路由前缀 /admin
管理端 Vue3 加 Element Plus，登录后按角色校验，统计图表用 ECharts 或 Element 内置组件。

1. 登录 /admin/login。
2. 首页统计 /admin/dashboard，概览卡片与琴房使用率图表。
3. 用户管理 /admin/users，搜索列表、会员设置、重置密码、信用操作入口。
4. 琴房管理 /admin/rooms，增删改、对内对外设置、可约时间窗、乐器明细编辑。
5. 预约管理 /admin/bookings，按日期、琴房、用户、状态查询，取消处理。
6. 规则参数 /admin/rules，参数列表与批量保存。
7. 信用管理 /admin/credits，用户信用查询、人工减分与恢复、流水查看。
8. 内容管理 /admin/content，轮播与公告管理，图片上传。
9. 反馈处理 /admin/feedback，反馈列表与状态处理。

## 三、说明
1. 用户端与管理端独立工程，共用后端 /api，角色权限由后端校验，前端按角色控制入口。
2. 用户端与管理端可合并为一个前端工程按 /admin 路由分包，搭建时定。
3. v1.1 候选页面须待接口清单 v0.3 评审通过后实现；RabbitMQ 为后端内部实现，前端只调用 REST 接口。
4. v1.1 候选增强的 RabbitMQ/Redis 为后端实现细节，用户端只消费排行榜与风控状态接口；消息队列不可用时页面显示“数据稍后更新”，不阻断预约主流程。
