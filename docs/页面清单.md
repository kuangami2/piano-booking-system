# 房间预约系统：页面清单

状态：v0.3，2026-09-15。页面均已实现，阶段 B 的排行榜与风控提示随接口 v0.6 收口；阶段 C 新增管理端事件概览页，用户端无变化。

## 一、用户端页面，路由前缀 /
用户端工程为 `frontend/user-web`，Vue3 加 Vite 加 Element Plus，开发端口 5173；各页面调用的接口见 接口清单.md。

1. 登录注册 /login，含注册、忘记密码与重置密码子视图；找回走申请令牌与凭令牌重置两步，邮件通道未接入时申请结果直接展示令牌便于联调。
2. 首页 /home，轮播、公告、琴房快捷搜索与入口。
3. 琴房列表 /rooms，对内对外筛选与关键字搜索，分页。
4. 琴房详情 /rooms/:id，琴房说明、乐器明细、注意事项、空闲查询、预约表单与空出提醒关注。
5. 我的预约 /bookings，按状态筛选，退约取消。
6. 我的关注 /watches，关注时段列表与取消。
7. 消息中心 /messages，站内提醒列表与已读。
8. 个人中心 /profile，资料展示、会员状态、修改密码。
9. 反馈 /feedback，提交反馈与我的反馈记录。

### v1.1 增强页面，已实现

10. 活跃度排行榜 /ranking/activity，展示周榜与月榜、本人排名与分数、数据更新时间与脱敏昵称；由开关 VITE_ACTIVITY_RANKING_ENABLED 控制。
11. 预约风控提示，复用 /rooms/:id 预约表单，命中临近取消黑名单时展示原因、解除时间与次数并禁用预约按钮，不展示其他用户的风控信息；由开关 VITE_NEAR_CANCEL_RISK_ENABLED 控制。

## 二、管理端页面
管理端工程为 `frontend/admin-web`，Vue3 加 Vite 加 Element Plus，开发端口 5174，独立工程不共用用户端路由。

1. 登录 /login。
2. 首页统计 /dashboard，概览卡片与琴房使用率图表。
3. 用户管理 /users，搜索列表、会员设置、重置密码、信用操作入口。
4. 琴房管理 /rooms，增删改、对内对外设置、可约时间窗、乐器明细编辑。
5. 预约管理 /bookings，按日期、琴房、用户、状态查询，取消处理。
6. 规则参数 /rules，18 条参数列表与批量保存，含阶段 B 新增九条。
7. 信用管理 /credits，用户信用查询、人工减分与恢复、流水查看。
8. 内容管理 /content，轮播与公告管理，图片上传。
9. 反馈处理 /feedback，反馈列表与状态处理。
10. 事件概览 /events，展示 MQ 运行模式、outbox 待投与已投数量、死信深度与重投次数、各事件类型计数与最近事件时间；broker 不可达时提示降级运行并隐藏不可用字段，不报错。

## 三、说明
1. 用户端与管理端为独立工程，共用后端 /api，角色权限由后端校验，前端按角色控制入口。
2. 阶段 B 两项增强页面默认由环境变量开关关闭，复制 .env.example 为 .env.local 并置为 true 后启用。
3. Redis 与 RabbitMQ 属后端实现细节，前端只消费排行榜与风控状态接口；增强数据不可用时页面显示稍后更新提示，不阻断预约主流程。
4. 阶段 C 事件概览页按后端返回的 mqEnabled 与 brokerReachable 展示运行模式，降级或不可达时只作提示，不阻断其他管理功能。
